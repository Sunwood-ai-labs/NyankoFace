# READMEと実装を同期する

READMEは紹介文ではなく、別の環境でプロジェクトを再構築するための入口です。実装変更と同じ単位で更新し、存在しない機能や古いコマンドを残さないようにします。

## 更新する情報

- 必要なソフトウェアとバージョン
- 初回起動、停止、更新のコマンド
- 公開URLと主要な画面
- 永続化されるデータと秘密情報の置き場所
- CI/CDとデプロイの流れ

コマンドはコピーして実行できる形にし、環境固有の値はプレースホルダーと実例を区別します。画面が変わった場合はスクリーンショットも撮り直し、画像内の情報と本文が矛盾していないことを確認します。

READMEから詳細ガイドへ自然に移動できるよう、重複説明ではなく役割の異なるリンクを設計します。
