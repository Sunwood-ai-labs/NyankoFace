# NyankoFace v0.1.0

NyankoFace v0.1.0は最初の公開リリースです。以前のリリースタグがないため、初回コミットから`main`までに完成した機能全体をまとめています。

## ハイライト

- **1台から始めるAIハブ:** Next.jsポータル、Forgejo、PostgreSQL、nginx、FastAPI製Docker runnerをDocker Composeで構成します。
- **実Gitリポジトリのカタログ:** Models、Datasets、Spaces、Characters、Benchmarks、Skills、MCPs、Prompts、Knowledge、Pagesが、Files、履歴、タグ、Issue、Pull Request、権限を保持します。
- **Dockerfile-firstのアプリ:** CPUで動くGradio、静的HTML、React、Vue、Next.js、Streamlit、FastAPI、Node.jsを同じgateway配下で実行できます。公開Spaceは未ログインでも起動でき、管理操作は保護されます。
- **複数の公開方法:** 埋め込みDocker Space、指定サイトへ直接移動する外部リンクSpace、`gh-pages`またはrepository docsから配信するPagesに対応します。
- **配備境界:** hardware固有のtopology、hostname、address、運用者向け接続経路は公開snapshotの外に置いています。
- **監査可能な自動保守:** Claude Code `/goal`、GLM、専門エージェント、SHA固定の独立レビュー、allowlist label、fail-closed auto-mergeをIssue／PR上に残します。
- **ナレッジ配信:** Git管理したMarkdownを、news、benchmark、how-to、referenceなど利用頻度の高いtopicで整理した日英ライブラリとして公開します。
- **画面品質の継続検証:** Standard／Solarpunk／Cyberpunk、日英、PC／モバイル、Markdown、Mermaid、操作状態を再実行可能なスクリーンショット監査で確認します。

## 運用とセキュリティ

- Forgejoをrepository、identity、organization、team、star、forkの正本にします。
- Spaceの閲覧／いいねは永続metrics APIを使い、取得不能時は架空の数値ではなく明示的な状態を表示します。
- repository Ownerは実行時Variableと暗号化Secretを管理できます。Secret値は保存後に返さず、container実行時だけ注入します。
- 配備固有のcredential、host情報、backup先、非公開network手順は公開repositoryの外で管理します。
- release branchではsecurity／documentation監査を独立実行し、Pull Requestへ証跡を返します。

## ツールと品質ゲート

- GitHub Actionsでfrontend、VitePress docs、NyankoFace Navigator Skill、Space runner、maintenance agentを検証します。
- Visual QAはroute、theme、viewport、scroll、organization、interaction、authentication、character、Spaceの挙動を撮影します。
- インストール可能なNyankoFace Navigator Skillが、用途に合う最小の公開方法の選択、雛形生成、検証を支援します。
- seed生成元と追跡対象Docker sampleを明文化し、再構築時も同じcatalog inputを使用できます。

## アップグレード

初回リリースのため、以前のNyankoFace releaseからのmigrationはありません。`.env.example`を`.env`へコピーし、ローカルcredentialを設定して、開発用Secretを流用せず現行Docker Compose手順で構築してください。

## 検証

release candidateはrepositoryのCI、VitePress production build、SVG validator、release QA inventory validatorで確認します。documentation deploymentの公開確認後に、最終tagとGitHub Releaseを作成します。
