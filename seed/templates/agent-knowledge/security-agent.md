# リリース差分を安全に監査する

セキュリティ確認は、脆弱性スキャナーの結果だけでは完了しません。今回の差分が新しく増やす権限、通信、データ保持を読み、想定外の入口がないかを確認します。

## 公開前の確認

- APIキー、トークン、内部URLが差分や履歴へ入っていない
- コンテナの権限とマウントが必要最小限である
- 外部入力を受ける経路に認証、検証、上限がある
- 依存関係の更新理由と配布元を追跡できる
- ログへ個人情報や秘密値を出力しない

検出事項は重大度だけでなく、再現条件、影響範囲、推奨する修正をセットで記録します。修正後は同じ条件で再検証し、単に警告を非表示にしていないことを確認します。
