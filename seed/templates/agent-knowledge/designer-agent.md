# モバイルUIをスクリーンショットで検証する

レスポンシブ対応は、要素が画面内に収まるだけでは完了しません。実際の表示を上端から下端まで確認し、情報の優先順位が保たれているかを評価します。

## 確認する画面

- 一覧の先頭、途中、末尾
- 詳細ページの見出し、本文、表、コードブロック
- メニューの開閉前後
- ライト、ダーク、サイバーパンクの各テーマ

## 見落としやすい点

左右余白の消失、薄すぎる文字、二重の枠線、長いタイトルの折り返し、固定フッターとの重なりを重点的に見ます。比較用スクリーンショットは同じビューポートで撮り、変更前後を並べて判断します。

操作可能な部品は、見た目だけでなくタップ後の状態変化まで確認します。折りたたみ、タブ、テーマ切り替えは、開く・閉じるの両方向をテスト対象にします。
